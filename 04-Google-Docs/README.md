# 4. Google Docs

## 4.1 Introduction
Google Docs is a cloud-based word processor in Google Workspace. It enables users to create and edit documents online and collaborate with others from different devices.

## 4.2 Key features
- Real-time multi-user collaboration.
- Rich formatting, including styles, headings, tables, images, drawings, links, and equations.
- Comments and suggestions for review and feedback.
- Version history to track changes and restore earlier states.
- Import and export formats such as DOCX, PDF, ODT, RTF, HTML, and TXT.

## 4.3 Collaboration
A document can be shared with other people using permissions such as Viewer, Commenter, or Editor. The appropriate permission depends on whether a person should only read, provide feedback, or edit the document.

## 4.4 Comments and suggestions
- Comments allow reviewers to leave feedback without directly changing the document text.
- Suggesting mode proposes edits that the document owner can accept or reject.
- Editing mode allows direct changes, subject to the user's permission.

## 4.5 Version history
Version history records document changes over time. Users can review earlier versions and restore a previous version when needed.

## 4.6 Practical exercise
1. Create a Google Doc.
2. Share it with a classmate using Commenter or Editor access.
3. Apply headings and text formatting.
4. Add a table and insert an image or diagram.
5. Add a comment and try Suggesting mode.
6. Open version history and inspect earlier changes.

## 4.7 What I learned
Google Docs supports fast document creation and collaborative editing. Sharing permissions, comments, suggestions, and version history make group work easier to manage.
