# Google Docs Collaboration Practice

- [ ] Create a new document.
- [ ] Rename the document.
- [ ] Apply heading styles.
- [ ] Insert a table or image.
- [ ] Share with a collaborator as Viewer.
- [ ] Change permission to Commenter or Editor when appropriate.
- [ ] Add a comment.
- [ ] Make a suggested edit.
- [ ] Review and resolve a comment.
- [ ] Open version history.
- [ ] Download the document as PDF.
