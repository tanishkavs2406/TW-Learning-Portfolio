# Sample Technical Report

**Document purpose:** Practise document organisation and formatting in Google Docs.

## 1. Introduction

Write a short introduction explaining the purpose of the report.

## 2. Main Content

Add the main discussion here. Use heading styles to organise subsections.

### 2.1 First Point

Add supporting information.

### 2.2 Second Point

Add another section of information.

## 3. Summary

Summarise the important points.

## 4. References

Add the sources used in the report.

---

## Formatting Practice

- Apply Title style to the document title.
- Apply Heading 1 and Heading 2 to section headings.
- Insert a table and an image.
- Add a hyperlink.
- Add a comment to a paragraph.
- Turn on Suggesting mode and make a suggested edit.
- Open version history and inspect earlier changes.
- Download a copy as PDF and DOCX.
