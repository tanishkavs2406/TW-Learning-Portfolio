# TW Learning Portfolio

**Technical Writing (TW) — Learning Documentation**

This repository records the concepts and practical skills I learned during Technical Writing. Each topic has a README with explanations and learning notes. Where practical samples are useful, they are kept in a separate `Examples/` folder.

## Topics

1. [LaTeX](01-LaTeX/README.md) — document structure, text formatting, mathematics, lists, tables, figures, and colours. Its examples are complete `.tex` source files.
2. [Beamer](02-Beamer/README.md) — creating presentation slides with the LaTeX Beamer class. Its sample presentation is a `.tex` source file.
3. [Doxygen](03-Doxygen/README.md) — documenting source code with specially formatted comments and generating documentation.
4. [Google Docs](04-Google-Docs/README.md) — document formatting, sharing, collaboration, comments, suggestions, and version history.
5. [Git and GitHub](05-Git-GitHub/README.md) — version control, repositories, commits, remotes, branches, merging, and collaboration.

## How this portfolio is organised

The READMEs focus on what I learned and explain the main concepts in my own learning notes. The `Examples/` folders keep the corresponding practical files separate. LaTeX and Beamer samples are written as LaTeX source (`.tex`); other topics use the file types appropriate to the tool being practised.
